Detailed Description

Implementacja modułu odpowiedzialnego za trwałość danych (zapis/odczyt).

  • Moduł wykorzystuje standardowe funkcje biblioteki stdio.h do operacji na plikach tekstowych. Dane są składowane w formacie kolumnowym, co ułatwia ich podgląd.
